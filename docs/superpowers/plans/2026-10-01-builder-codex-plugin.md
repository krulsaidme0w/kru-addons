# Builder Codex Plugin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Builder MCP tools and Minecraft build-planning skills available to Codex through a repo-scoped plugin without modifying global Codex identity or configuration.

**Architecture:** Package the MCP companion and one focused build-planning skill in a Codex plugin rooted in the repository. A repository-local marketplace/config enables the plugin only for this trusted workspace. The skill teaches discovery → world read → block research → plan inspection → preview publication and links back to saved plans, while Codex itself retains the conversation history.

**Tech Stack:** Codex local plugin format, stdio MCP server from prior plans, Markdown `SKILL.md`, JSON manifests, project-local `.agents/plugins/marketplace.json` and `.codex/config.toml`.

**Spec:** `docs/superpowers/specs/2026-10-01-builder-local-mcp-world-design.md`

## Global Constraints

- Do not write to `~/.codex`, global credentials, global skills, or user `config.toml`.
- Plugin MCP command launches a packaged local process with an explicit Java 21 requirement and no download-at-runtime behavior.
- Skill directs the agent to exact catalog tools and strict plan operations; it does not grant shell, arbitrary files, commands, or world-write tools.
- Create a new Codex session after plugin tool/skill manifest changes.

## Review Focus

- Untrusted repositories must not start MCP or hooks before Codex trusts/enables the project — test disabled-by-default/local enable behavior.
- A missing Java runtime or artifact must show a clear setup failure — test launch diagnostics.
- MCP startup logs must not corrupt stdio or reveal pairing tokens — test startup with captured streams.
- Codex clients with different plugin support must still have documented direct MCP setup — test generated setup docs against manifests.
- The skill must not imply visibility into conversation APIs or world mutation abilities — contract test and manual wording review.
