THESIS: A survey workbench for translating the player's bounded Minecraft region into a traceable construction proposal.
OWN-WORLD: Orienteering map meets precise field instrument: charcoal instrument panels frame warm, muted terrain-paper schematic; purple marks active focus, green/amber/red distinguish place/replace/remove.
STORY: Choose a saved revision → orbit and slice the selected region → hover a cell for exact state/coordinates → compare stages and validation evidence.
FIRST VIEWPORT: Persistent revision rail on the left, large rotatable schematic in the center, compact inspection/report column on the right; at narrow widths, stack history, map, then inspector.
FORM: Quiet Codex-like utility chrome around a tactile survey-map canvas. Strong hierarchy comes from exact IDs, coordinates, stage and validation status—not decoration. Keyboard rotate/zoom and visible focus states are required.
FINISH: The rendered schematic is explicitly an ID-color approximation, never presented as mod geometry; the in-game preview and captured block thumbnails remain authoritative.
